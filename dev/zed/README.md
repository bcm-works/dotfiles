# Zed Editor Configuration

To install [Zed Editor](https://zed.dev/) and load my config ([settings.json](settings.json)):

1. Optional: Install the custom font by running [/fonts/fonts-setup.sh](../../fonts/fonts-setup.sh)
2. Install and configure Zed by running [zed-setup.sh](zed-setup.sh): `bash ./zed-setup.sh`

For more information about the available configuration options for these files, refer to the [Configuring Zed](https://zed.dev/docs/configuring-zed) and [User Keymaps](https://zed.dev/docs/key-bindings) pages.
